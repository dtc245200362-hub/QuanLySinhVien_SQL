# Quản Lý Lô Hàng (quan_ly_lo_hang)

Ứng dụng web cơ bản cho phép quản lý và gộp các lô hàng nhỏ cùng loại sản phẩm thành một lô lớn duy nhất.

## Cấu trúc thư mục
- `index.html`: Giao diện chính của ứng dụng.
- `css/style.css`: Định dạng giao diện và bảng biểu.
- `js/main.js`: Xử lý logic gộp lô và tương tác giao diện.

## Cách chạy dự án
1. Mở thư mục `quan_ly_lo_hang` bằng VS Code.
2. Dùng extension **Live Server** hoặc bấm đúp vào file `index.html` để mở trên trình duyệt.
3. Bấm nút **"Gộp các lô cùng sản phẩm"** để xem kết quả.
